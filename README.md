# 研途 · 考研目标任务管理

研途是一套围绕“当前考研目标 → 科目 → 可选阶段/学习内容 → 学习任务 → 每日执行 → 完成反馈 → 进度调整”设计的响应式网页应用。

## 当前版本

- 数据只保存在当前浏览器的 IndexedDB，不要求账号，也不会上传。
- 支持单一当前考研目标、科目、科目独立阶段和任意层级学习内容。
- 支持普通任务、数量进度任务、日期/截止日期、自动顺延和重复任务。
- 支持任务编辑/归档、一键完成、可选实际耗时与掌握程度反馈。
- 支持正计时、倒计时、每日目标时长、七天计划、加权进度和近七天复盘。
- 支持 JSON 全量备份与恢复；云同步目前仅保留产品入口。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开开发服务器给出的本地网址即可。第一次进入会先设置当前考研目标和科目。

## 使用 Netlify 部署

项目已提供 `netlify.toml`。在 Netlify 连接仓库时，若仓库根目录就是本项目，直接使用默认根目录即可；若把外层目录作为仓库，则将 Base directory 设为 `app`。构建命令使用 `pnpm run build:netlify`，Node.js 版本使用 22.13 或更高版本，发布目录交给 Nitro 的 Netlify 适配器处理即可。

## 使用 Vercel 部署

项目已提供 `vercel.json` 和 `build:vercel` 脚本。Vercel CLI 或项目设置使用项目根目录，构建命令为 `pnpm run build:vercel`，输出目录为 `.vercel/output`，Node.js 版本使用 22.13 或更高版本。该目录由 Nitro 的 Vercel 适配器生成，不要手工上传构建产物。

## 验证

```bash
pnpm lint
pnpm test
```

`npm test` 会先完成生产构建，再验证服务端输出。核心数据结构说明见 [`docs/data-model-v1.md`](docs/data-model-v1.md)。

## 数据提醒

浏览器本地数据可能因清除网站数据、更换浏览器或更换电脑而丢失。请定期在“设置 → 本地数据与备份”中导出 JSON 文件。
